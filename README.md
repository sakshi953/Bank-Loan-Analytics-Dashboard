# Bank Loan Analytics Dashboard

An interactive **Power BI dashboard** developed to analyze bank loan data and provide clear insights into loan applications, funded amounts, repayment performance, and customer/loan trends.

## Dashboard

![Bank Loan Analytics Dashboard](screenshots/overview.png)

## Key Analysis

* Total Loan Applications
* Total Funded Amount
* Total Amount Received
* Average Interest Rate
* Average Debt-to-Income Ratio (DTI)
* Loan Status Analysis
* Monthly Loan Trends
* Loan Purpose Analysis
* Home Ownership Analysis
* Loan Term Analysis
* Good Loan vs Bad Loan Performance

## Tools Used

* **Power BI**
* **Power Query**
* **DAX**
* **Excel**

## Key Features

* Interactive KPI cards
* Dynamic slicers and filters
* Loan performance analysis
* Trend analysis
* Customer and loan segmentation
* Interactive visualizations for business insights

## Project Objective

To transform raw bank loan data into an interactive dashboard that helps understand **loan performance, customer behavior, and key financial trends** for better data-driven decision making.
